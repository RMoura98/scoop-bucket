# Scoop bucket for Yonder

Scoop bucket for [Yonder](https://github.com/RMoura98/yonder), the free, open-source break reminder.

## Install

```powershell
scoop bucket add yonder https://github.com/RMoura98/scoop-bucket
scoop install yonder/yonder
```

## Update

```powershell
scoop update yonder
```
